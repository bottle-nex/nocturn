# Nocturn — Design Language

This document defines the core visual language of the Nocturn application.  
The goal is to maintain a consistent, expressive, and accessible interface across all platforms while preserving a bold, nocturnal personality.

---

## Color Philosophy

Nocturn’s palette is built around deep, moody bases contrasted with sharp, emotional accents.  
The colors are designed to feel confident, slightly rebellious, and modern—never loud, never dull.

The system follows a **dark-first approach**, with light tones used intentionally for contrast, focus, and readability.

---

## Core Accent Palette

These colors form the emotional and brand core of the application.

| ------- | --------- | ---------------------------------------------------------------------------------- |
| alpha   | `#E84545` | Primary accent. High-energy red used for CTAs, errors, and critical highlights.    |
| beta    | `#903749` | Secondary accent. Muted crimson for hover states, secondary actions, and emphasis. |
| charlie | `#53354A` | Support tone. Deep wine used for surfaces, cards, and layered UI elements.         |

## Dark Mode Color System

Dark mode is the default visual mode of Nocturn.  
It prioritizes depth, contrast, and reduced eye strain.

| Token       | Hex       | Usage                                      |
| ----------- | --------- | ------------------------------------------ |
| dark-alpha  | `#2B2E4A` | Main application background                |
| dark-base   | `#53354A` | Cards, modals, elevated surfaces           |
| light-alpha | `#F3ECE7` | Primary text and icons                     |
| light-base  | `#903749` | Secondary text, borders, subtle highlights |

---

## Usage Guidelines

- **alpha** should be used sparingly to preserve impact
- **delta** and **charlie** should dominate layouts and surfaces
- **gamma** ensures readability and calm contrast
- Avoid pure white or pure black; stay within the defined system
- Gradients, if used, should stay within the palette family

---

## Design Intent

Nocturn’s design language balances **system-level seriousness** with **emotional edge**.  
It is meant to feel composed, slightly dangerous, and unmistakably intentional.

Every screen should feel like it belongs to the same night.
